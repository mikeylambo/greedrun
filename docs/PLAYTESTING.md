# GreedRun — Playtesting Checklist

For a structured playtest of the web build. Work top to bottom; the readability
section is the current highest-risk area (new floor treatment + small sprites).

Capture data with the built-in **"Copy playtest report"** in the hideout — it
logs every run (location, twist, outcome, payout) into paste-able text.

## Setup / coverage

- [ ] Desktop: Chrome, Firefox, Safari.
- [ ] Mobile: iOS Safari, Android Chrome — real devices, portrait + landscape.
- [ ] Fresh save (first-time flow) **and** a returning save (skips tutorial).
- [ ] A run that rolls the bright floor (A) as well as the dark treatments.

## First-time experience

- [ ] The first job teaches the loop: does TAKE → WATCH → LOAD → LEAVE land
      through the player's own actions?
- [ ] Is "Skip tutorial" discoverable for players who don't want it?
- [ ] Do the Tact reads fire once, persist, and get out of the way? Any that
      confuse or land at the wrong moment?
- [ ] Transition from the authored first job into a real vault feels smooth.

## Readability (highest risk right now)

- [ ] You can **always** locate Jo on the floor — across all four floor
      treatments, including the bright A roll.
- [ ] Guards read as threats *before* they catch you: eye glow + vision cone
      visible on the dark/vignetted floors.
- [ ] Loot is legible at phone density; distinct loot types are distinguishable
      from each other at a glance.
- [ ] HUD stays legible over textured floors — hearts, haul, meters, heat.
- [ ] Stairs / exits / the extraction point read at a glance.

## Core loop & feel

- [ ] The greed-vs-heat tension is fun; you feel the "one more thing" pull.
- [ ] Haul / greed-load / heat feedback is clear and responsive.
- [ ] Movement feels good: Shadow Step, footsteps/noise, the Mirage toolkit.
- [ ] Getting spotted / the chase feels fair and tense, not cheap.

## Economy & progression

- [ ] Rewards feel worth the risk; buyer choices (Keep / Return / sell-to) matter.
- [ ] Trophy restore costs are a real gold sink, not trivial or grindy.
- [ ] Commissions feel varied across a session (client archetypes, objectives).
- [ ] Upgrades feel meaningful and worth saving for.
- [ ] The Generous Gift lands emotionally and its trade (reach vs. gold) is clear.

## Balance & difficulty

- [ ] Difficulty curve across a session feels earned, not spiky.
- [ ] No dominant/degenerate strategy that trivializes runs.
- [ ] Heat and guard escalation scale sensibly with greed.

## Edge cases & special loot

- [ ] Porcelain/fragile relic shatter state.
- [ ] Skitterjewel flee behavior (all directions).
- [ ] Decision Artifact, Vault Heart, and the "One More Thing" moment.
- [ ] Gilded Fake vs. real idol tell (Appraiser's Eye).

## Stability & performance

- [ ] Frame rate holds on mobile, including long/loot-heavy runs.
- [ ] Save/migration survives across versions (gold, upgrades, toolkit,
      collection, seen-Tacts).
- [ ] No console errors across a full session (menus → run → fence → repeat).

## After the session

- [ ] Export the playtest report and file the top 3 friction points.
- [ ] Note anything that broke immersion or readability for the punch-list.
